# Technical Debt and Risks

Priorities: **P0** = critical blocker to safe use; **P1** = high-risk issue to resolve before production; **P2** = important quality/reliability gap; **P3** = lower-priority cleanup.

| ID | Priority | Finding | Evidence / affected area | Impact | Recommended resolution / verification |
|---|---|---|---|---|---|
| SEC-001 | P1 | Public config serialization returns raw secret values, including Gemini and legacy TikTok keys. Route access control was not verified. | `A/src/config/index.js` `toPublicJSON()`; `/api/config` controller/route | Credential disclosure if endpoint is reachable by an unauthorized client. | Inspect middleware/network exposure; return only configured/masked flags to UI; test unauthorized access and prevent secret echo. |
| TTK-001 | P1 | JuleTik wrapper stores reconnect options but does not implement automatic retries or bounded reconnect behavior. | `A/src/integrations/tiktok/juleTikSdk.js` constructor/disconnect/connect | Stream interruptions can leave service disconnected despite options promising retry. | Add explicit state machine, timeout/backoff/cancel and tests, or remove unsupported options and delegate reconnect to one owner. |
| TTK-002 | P1 | No actual TikTok live connection/event integration test was run. Unit tests only check payload helpers and empty username. | `A/test/juleTikSdk.test.js` | False confidence about access, handshake, WAF, offline room and event delivery. | Add connector-mocked integration tests, then execute an authorized live test; label supported events by evidence. |
| TTK-003 | P1 | A retains legacy API-key config, save path, status fields, viewer options, and error text although the UI no longer presents the key and primary startup no longer requires it. | `A/src/config/index.js`, config controller, `tiktokService.js`, `tiktokViewer.js`, `.env.example`, README | Confusing contract and misleading errors; possibly accidental secret exposure. | Inventory all consumers; define migration/deprecation; preserve existing user config until safe; remove or document legacy path with tests. |
| TTK-004 | P2 | Connection test endpoint indicates configuration readiness, not a verified room connection; a username-only response is not a live test. | `A/src/api/controllers/configController.js`; front-end helper in `A/app/app.js` | UI can overstate readiness if called or wired later. | Rename endpoint/action to config validation or implement a real bounded connection probe and report exact state. |
| TTK-005 | P2 | Event coverage tests are incomplete: only chat/gift normalization are tested; follow/share/like/member and duplicate-listener behavior are not. | JuleTik SDK and `A/test/juleTikSdk.test.js` | Event contract regressions may go unnoticed. | Test all supported events, payload normalization, cleanup, duplicate prevention, stream end and error paths. |
